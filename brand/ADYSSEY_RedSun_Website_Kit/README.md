# Adyssey · Red Sun website kit

Light mode is day: paper, ink and a red sun. Dark mode is night: night, cream and a red crescent moon.
This kit replaces the first logo kit (`brand/ADYSSEY_Logo_Website_Kit`): its logo red (#FF3B30) and aura pictures are retired.

| Folder | What is inside |
|---|---|
| `01_Logo_SVG` | Every logo as `-day` (ink + sun red #B8241B), `-night` (cream #F3EBE0 + REC red #FF5A48), `-auto` (switches with the device), and `-white` / `-black` (one colour). Plus `adyssey-sun-badge.svg` and `adyssey-moon-badge.svg`. |
| `02_Logo_PNG` | See-through PNGs for email, slides, Word and Canva. |
| `03_Logo_WebP` | Smaller WebP versions for the web. |
| `04_Favicon_and_App_Icons` | `favicon.ico`, `favicon.svg` (bold A on the red sun), `favicon-16/32/48/96`, `apple-touch-icon.png`, `icon-192/512`, `icon-maskable-512`, `safari-pinned-tab.svg`, `site.webmanifest`. |
| `05_Link_Preview` | `og-image-day-1200x630.jpg` (the default) and `og-image-night-1200x630.jpg` (night campaigns). |
| `06_Hero_Backgrounds` | The desert scene, day and night, 1920 × 1080, as JPG and WebP. |
| `07_Craft_Icons` | The four craft symbols: `-day` (ink, REC parts in sun red) and `-night` (sand #E3CFAE, REC parts in REC red). |
| `head-code.html` | The code to copy into a site: icons, link preview, colours, header logo, the sun and moon switch. |

## Rules

- Day files on light grounds, night files on dark grounds. Never a red A on the red sun: on the sun the A is paper.
- Header logo at least 160px wide; the A alone at least 48px.
- Never stretch, recolour or redraw the logo. These files are the original drawing, recoloured only.
- No orange, violet or pink anywhere.

Not made yet: the 2880 × 1620 and phone (1080 × 1920) hero scenes, and a Red Sun version of the logo animation.
